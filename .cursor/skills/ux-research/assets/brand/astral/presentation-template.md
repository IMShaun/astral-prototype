# Presentation template

Use the IMSERV Brand Book Presentation Deck recipes. Do not invent slide chrome.

Open `assets/brand/pages/` through the desk preview. Pick a family. Type over the placeholders. Present is fullscreen. Print this page saves a 16:9 PDF.

## Board

1920 × 1080. 40px inset. 40px gutter. 128px cover grid. Roobert Medium. Semibold only for small labels. Pairings stay black on white, white on black, cyan on black, and black on cyan. Do not put cyan type on white.

## Suggested narrative

Cover uses Title. Section breaks use Divider split or Divider field. Evidence tables use Table ruled. People use People. Findings use Three cards or Four up. A large number uses Stat split. A drawing uses Illustration.

Every insight slide still needs an evidence marker. Every quote still links to its source. Sharing stays within consent.

If a deck is required and you cannot open the page maker, produce an outline in Markdown labelled **neutral draft**, with every claim linked to evidence.
