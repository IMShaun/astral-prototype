# Presentation and reporting

Generate decks and reports **only when asked**, from repository evidence, not from memory.

Suggested narrative:

```
Research question
What we did
Who participated
What we learned
Key themes
Key insights
Behavioural archetypes
Journey implications
Experience measures
What improved / deteriorated
Recommendations
Knowledge gaps / next steps
```

Executive summary variant: What we tested → What we learned → What matters → Evidence → User behaviours → Experience measures → Recommended actions → What we still need to learn.

Every insight slide carries an evidence marker, for example:

```
Evidence: 6/8 participants · Study R04 · P01, P03, P04, P06, P07, P08
```

Every quote links to its source. Concise quotations with participant numbers. Sharing must stay within consent. See [consent-and-privacy.md](consent-and-privacy.md).

Load the active brand before rendering. Do not redesign the brand. If no brand pack exists, labelled **neutral draft** only.

Distinguish fact/observation, interpretation, hypothesis, and recommendation. Do not present hypotheses as findings.
