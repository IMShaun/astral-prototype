# Method selection

Select the method from the question. Do not default to a usability script.

| Research question | Preferred starting method |
| --- | --- |
| Can someone complete this task? | Moderated usability test |
| Why do people behave this way? | Interview / contextual research |
| What do people currently do? | Contextual inquiry / interview + behavioural evidence |
| Do people understand this concept? | Concept / comprehension testing |
| Which information architecture works? | Tree test / card sort where appropriate |
| How common is this behaviour? | Quantitative survey / analytics |
| Is UX improving? | Benchmark usability study + longitudinal metrics |
| Why is a metric changing? | Mixed methods |

Interviews help understand users, circumstances, needs, and problems. Usability testing is appropriate when observing people attempt realistic tasks with an interface or prototype.

Never answer “How many customers have this problem?” with five interviews.

If existing evidence already answers the decision, recommend **no new study**. State what to reuse.

Accessibility and safety constraints can make research on a flow urgent even when sample size will stay directional.
