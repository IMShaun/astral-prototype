# Objectives

Write objectives as things the study genuinely needs to understand.

Prefer: Understand, Evaluate, Identify, Explore, Determine, Gauge, Assess.

Examples:

- Understand how administrators currently determine which companies a user should have access to.
- Evaluate whether administrators can create a company and configure access without assistance.
- Identify terminology that causes misunderstanding between Company, Team, and third-party access.
- Understand what information administrators require before feeling confident enough to confirm access.

Avoid: “Get feedback.” “See what people think.” “Test the design.”

Every significant objective maps to:

```
Objective → research question → activity/task → evidence type → measure where appropriate
```

After analysis, check whether each objective was actually answered. Unanswered objectives become knowledge gaps, not invented findings.
