# Question writing

Use neutral research language.

Avoid:

- leading questions
- loaded language
- asking participants to predict behaviour when behaviour can be observed
- combining several questions unnecessarily
- teaching the interface before testing comprehension
- asking “Do you like this?” without understanding why

Prefer:

- “What do you think is happening here?”
- “What would you expect to happen next?”
- “Tell me about the last time you did this.”
- “What are you looking for?”
- “What would you do next?”
- “What, if anything, is unclear?”
- “What makes you say that?”

When testing a page, a short neutral probe block is allowed only where it serves an objective. Do not ask every probe on every screen.

For ratings, attach them to a named objective (clarity, confidence, ease). Do not add scores for atmosphere.
