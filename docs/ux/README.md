# UX pattern memory

Reusable product patterns for Astral. This folder is product evidence, not Cursor-only notes.

The method lives in `.cursor/skills/ux-patterns/`. Invoke `/ux-patterns` to inspect the product, recommend one change, and wait for Yes before editing.

## What belongs here

| Path | Role |
| --- | --- |
| `pattern-inventory.yml` | Index of known patterns. Empty until a review fills it from inspected evidence. |
| `patterns/` | Pattern guidance once a pattern is documented. |
| `decisions/` | UX decision records (UXDRs) for meaningful keep-or-change choices. |

Do not invent patterns. Desk recipes named in talks still live in `data/design-systems.json` under Patterns. That list is not automatically copied here.

## Maturity and health

Maturity is emerging, established, or deprecated. Health is healthy, inconsistent, or needs-evidence. Track them separately.

## After "learn it"

When the user says "learn it", the lesson from the latest change is recorded here or in the UX writing skill. Routing and format live in `.cursor/rules/learn-it.mdc`.

## After `/ux-patterns`

Read-only until Yes. Approved reusable changes update the inventory and, when useful, a pattern document and a UXDR in the same change.
